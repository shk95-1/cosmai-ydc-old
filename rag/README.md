> 수호님 `slopindustries/RAG_-` 를 우리 리포로 합치면서 네 곳을 고쳤습니다.
> 2026.08.26

---

## 무엇인가

질의 유형에 맞는 검색기로 찾고 **원문 근거를 그대로** 보여줍니다.
LLM 은 결론을 만들지 않습니다 — 규칙이 후보를 정하고, 검색이 근거를 찾고,
LLM 은 그 근거를 문장으로 묶는 마지막 층입니다.

```
질의
  → 규칙 라우팅 (rag/router.py — LLM 안 씀)
  → 검색 (bm25.py · hybrid.py · vector_threshold.df_gate)
  → 근거 + doc_id + 토큰 df + 한계
  → (선택) LLM 이 인용 달아 답변
```

## 띄우기

```bash
python -m rag.server                 # BM25 만 · 20초쯤
python -m rag.server --vectors       # 벡터까지 · 900MB 로딩
```

`http://127.0.0.1:8765` — 탭 셋(질의 / Opportunity Card / 지표와 한계).
**표준 라이브러리만 씁니다.** Flask·FastAPI 를 넣지 않았습니다.

```bash
python -m rag.router --demo          # 라우팅 14건
python -m rag.engine --demo          # 검색 4경로
python -m rag.generate --demo        # 프롬프트 조립
python -m rag.server --demo          # 카드·지표·ui 점검
python -m rag.engine --query "판테놀 쓰는 선크림"
```

LLM 답변은 `ANTHROPIC_API_KEY` 와 `anthropic` 패키지가 있을 때만 돕니다.
**없어도 쓸모가 있습니다** — 근거와 프롬프트를 그대로 냅니다.

## 수호님 판에서 고친 네 곳

### ① 성분명 목록을 토크나이저 사전에서 성분표로

`seeds/ingredient_dictionary.tsv` 는 **Kiwi 토크나이저 사전**이고 담론어가 일부러
들어 있습니다(`선크림`·`백탁`·`톤업`). 그걸 "성분명 목록" 으로 쓰면 자연어 질의가
전부 BM25 로 갑니다. **실측으로 자연어 10개 중 7개가 오라우팅**됐습니다.

```
선크림 루틴 알려줘        -> ['선크림','루틴']  -> bm25   (벡터로 가야 합니다)
백탁 관련해서 소비자들이     -> ['백탁']         -> bm25
끈적이지 않는 선크림 추천    -> ['선크림']        -> bm25
```

정본은 성분표의 `ingredient` 컬럼에서 **주제 별칭을 빼고** 마커를 정리한 1,851종입니다
(`rag/ingredients.json`). 라우팅 14건 테스트로 고정했습니다.

### ② `multi_source` 를 실제로 만듦

수호님 독스트링이 규칙 7 로 약속했는데 코드가 안 만들고 있었습니다
(`force_multi_source` 로 손으로 켜야 했습니다). 그래서 검증 케이스
"백탁 관련해서 소비자들이" 가 **라우터를 우회**했고 위 오라우팅이 테스트에 안 걸렸습니다.

정확 신호와 자연어 신호가 **같이** 있으면 둘 다 돌려 나란히 놓습니다.
이진 라우팅으로는 `콜라겐 들어간 제품 뭐가 좋아` 를 못 풉니다 — `콜라겐` 은 진짜
성분이면서 담론어입니다. 길이·빈도로 갈라 보려 했는데 안 갈렸습니다
(콜라겐 담론/제품 비율 281 · 판테놀 7). **갈라지지 않으면 고르지 말고 둘 다 냅니다.**

단 **등록번호·SPF 는 예외**입니다. 10자리 보고번호는 유일 식별자라 문장이어도 조회입니다.

### ③ `df_gate` 를 강화 — 수호님 §8-1 미결이 풀렸습니다

초판 규칙은 "토큰이 **전부** df=0" 일 때만 막아서 `크소나이드 함유 제품 있어` 를
통과시켰습니다 — `제품`(df 30,061)·`함유`(454)가 있으니까요.

실측으로 문턱을 정했습니다.

| 규칙 | 진짜 61 | 문장 7 | 가짜 15 |
|---|---:|---:|---:|
| 전부 0 (초판) | 1 막힘 | 0 막힘 | **10** 막힘 |
| 하나라도 0 · `len>=3` | 1 막힘 | 0 막힘 | 14 막힘 |
| **하나라도 0 · `len>=4`** | **0 막힘** | **0 막힘** | **14** 막힘 |

**정탐 손실 0 인데 오탐 차단이 10 → 14** 입니다. 4글자로 자르는 이유는 짧은
성분명(`루틴`·`산소`)이 부분문자열로 df=0 이 될 수 있어서입니다.
못 막는 하나는 키릴 문자 질의인데 토큰이 0개라 그 앞에서 걸러집니다.

### ④ `os.chdir` 를 임포트 시점에서 걷어냄 · pandas 제거

그의 `search_v2.py` 는 임포트 때 작업 디렉터리를 바꿨습니다(`bm25.py` 가 사전을
상대경로로 찾기 때문). 임포트가 프로세스 전역 상태를 바꾸면 서버처럼 여러 모듈이
함께 도는 곳에서 조용히 깨집니다. **리포 루트 안에서만** 쓰고 되돌립니다.

`pandas` 는 CSV 두 개 읽는 데 필요 없어 `csv` 로 바꿨습니다.

## 우리가 만든 것 중 하나를 더 고쳤습니다

**`gated` 와 `unavailable` 을 섞고 있었습니다.** 둘 다 "결과 0건" 이지만 뜻이 정반대입니다.

```
gated        질의 토큰이 코퍼스에 없다 — **판단**이다. 근거가 없는 게 맞다
unavailable  벡터를 안 올렸다 — **운영 상태**다. 근거가 없는지는 알 수 없다
```

섞으면 `백탁이 심해요`(df 338)에 **"근거 없음"이라는 거짓**을 말합니다. 갈랐습니다.

## 라우팅 규칙

| 신호 | 라우팅 | 근거 |
|---|---|---|
| 등록번호(10자리) · SPF/PA | `bm25` | 유일 식별자·표기. 문장이어도 조회다 |
| 성분명 · 브랜드만 | `bm25` | `literal P@10 0.841` |
| 성분명·브랜드 **+ 자연어** | `multi_source` | 둘 다 돌려 소스별로 나란히 |
| 시점 표현(`최근`·`요즘`) | `temporal_filter` | `report_date` 필터. **검색이 아니다** |
| 그 외 | `vector` | `heldout` 에서 BM25 는 0.000, 벡터만 0.038 |

자연어 판정은 **Kiwi 가 서술어(VA·VV·EF·EC)를 보고** 합니다. 길이만으로는 안 갈립니다 —
`백탁이 심해요` 는 12자인데 문장이고 `에칠헥실트리아존` 은 9자인데 낱말입니다.
