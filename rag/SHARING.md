# 이 GUI 를 남에게 보여주려면 — 조사 결과 (만들지는 않았습니다)

> 2026.08.27 · 김시현
> **결론: Tailscale 이 답이고 이미 깔려 있습니다. 다만 API 키 문제는 따로 풀어야 합니다.**

---

## 먼저 — 걱정하신 게 맞습니다

이 서버는 **자기 서버에서 `.env` 의 API 키로 LLM 을 부릅니다.** 링크를 받은 사람은
키를 볼 수는 없지만 **쓸 수는 있습니다.** 질의 한 번이 그대로 비용입니다.

그래서 "누가 접근할 수 있나" 와 "접근한 사람이 무엇을 할 수 있나" 를 나눠서 봐야
합니다. 아래 표의 왼쪽이 첫 번째, 오른쪽 절이 두 번째입니다.

---

## 접근 경로 네 가지

| 방법 | 누가 볼 수 있나 | 공개 노출 | 준비 |
|---|---|---|---|
| **Tailscale (권장)** | tailnet 에 초대된 사람만 | **없음** | **이미 깔려 있음** |
| Tailscale Funnel | **인터넷 전체** | 있음 | 명령 한 줄 |
| ngrok · Cloudflare Tunnel | URL 을 아는 누구나 | 있음 | 설치 필요 |
| 정적 배포(Artifact 등) | 링크를 받은 사람 | 있음(정적) | 질의 기능 없음 |

### 1. Tailscale — 이게 답입니다

**팀이 이미 쓰고 있습니다.** 확인한 상태입니다.

```
100.95.61.14     desktop-u75tsal                  (시현님, 이 서버가 도는 곳)
100.106.220.24   shk-hc-laptop.tail662690.ts.net  (석현님, 온라인)
100.96.113.69                                     (현준님 DGX)
```

서버를 tailnet 주소에 묶으면 됩니다.

```bash
python -m rag.server --host 100.95.61.14 --vectors
```

그러면 팀원은 `http://100.95.61.14:8765` 로 들어옵니다. **공개 인터넷에는
아무것도 안 열립니다.** 방화벽·포트포워딩·도메인이 필요 없습니다.

지금 기본값은 `127.0.0.1` 이라 **이 노트북 밖에서는 아예 안 보입니다.**
바꾸지 않으면 지금 상태 그대로 안전합니다.

### 2. Tailscale Funnel — 쓰지 마세요

`tailscale funnel 8765` 한 줄이면 `https://<장비>.ts.net` 이 **인터넷 전체에**
열립니다. URL 을 아는 누구나 시현님 키로 LLM 을 부를 수 있습니다.

### 3. ngrok · Cloudflare Tunnel — 같은 이유로 권하지 않습니다

임의 URL 이라 검색에는 안 걸리지만, 흘러 나가면 되돌릴 수 없습니다.

### 4. 정적 배포 — 질의를 포기하면 가장 안전합니다

카드·지표·범위만 담은 정적 페이지는 서버가 없어 키도 없습니다.
**`reports/viz_dashboard.html` 이 이미 그것입니다** — 아티팩트로 올려 뒀습니다.
질의 기능만 빠집니다.

---

## 접근을 허용했을 때 — 비용을 막는 세 가지

Tailscale 로 좁혀도 **tailnet 안 사람은 누구나 키를 씁니다.** 지금 코드에 이미
있는 것과 없는 것을 나눠 적습니다.

| 장치 | 지금 | 비고 |
|---|---|---|
| 근거 0건이면 LLM 을 안 부름 | **있음** | `generate()` 가 규칙 3 을 먼저 적용 |
| df 게이트로 호출 전 차단 | **있음** | 없는 성분 질의는 비용 0 |
| 생성 기본 꺼짐 | **없음** | 지금은 체크박스가 기본 켜짐 |
| 호출 수 상한 | 없음 | 분당·일별 상한이 없음 |
| 사용자 구분 | 없음 | 누가 얼마나 썼는지 모름 |

**가장 싼 대책은 생성 체크박스를 기본 꺼짐으로 두는 것**입니다. 검색과 근거는
키 없이도 다 보이고, 답변이 필요할 때만 켜면 됩니다. `ui.html` 의
`<input type="checkbox" id="gen" checked>` 에서 `checked` 를 빼면 됩니다.

## 권장

1. **지금처럼 `127.0.0.1` 로 두고 화면 공유로 보여주기** — 발표 전까지는 이걸로 충분합니다
2. 팀원이 직접 만져야 하면 **Tailscale 주소로 바인딩**하고 **생성은 기본 꺼짐**
3. **Funnel·ngrok 은 쓰지 않습니다**
4. 사외에 보여줄 일이 생기면 **정적 대시보드(`viz_dashboard.html`)** 만 공유합니다

`--host` 옵션은 이미 있습니다. 켜는 건 시현님 판단입니다 — 코드를 미리 바꿔 두지
않았습니다.
