## 1. 모집단 — 이 네 줄이 전부

수집은 43채널 전부 받고, **집계에서 걸러냅니다.**

| 단계 | 남는 수 |
|---|---|
| 수집한 영상 | 13,979편 (43채널, 2023-07-01 이후) |
| `panel_role = product`만 (34채널, expert 9채널 제외) | |
| **장문만** (60초 초과. 쇼츠·라이브 제외) | |
| **선크림 언급만** (제목+설명에 선크림 별칭 8개) | **964편** |
| 그 영상에 달린 댓글 | **60,348건** (중복 제외 60,311) |

기간은 **2023Q3~2026Q3 13분기**입니다.

**쇼츠를 뺀 이유**: 쇼츠는 설명 길이 중앙값 0자에 주제 매칭률 24.3%, 장문은 991자에 64.4%입니다. 게다가 분기별 쇼츠 비중이 55%→41%로 움직여서, 한 분모에 넣으면 **제작자의 포맷 선택 변화만으로 모든 주제 값이 흔들립니다.**

**expert를 뺀 것은 결론에 영향이 없습니다.** 넣고 빼서 재봤더니 판정 22셀 중 뒤집힌 것 0개, 최대 차이 0.58%p였습니다(`reports/panel_sensitivity.csv`).

| | |
|---|---|

| 댓글 text | 본문 |

| 분기 배정 | 영상은 `published_at`. **댓글은 부모 영상의 분기** |

**댓글 분기가 중요합니다.** 댓글은 자기 시각을 쓰면 안 됩니다. 3년 전 영상에 어제 댓글이 달리므로, 댓글 시각으로 나누면 "그 분기에 큰 영상 하나가 올라온 것"이 "그 주제 급증"으로 보입니다.

## 3. 트렌드를 무엇으로 봤나 — 여기가 핵심

### 빈도(언급량)를 직접 쓰지 않습니다

```
composition = 그 주제를 언급한 문서 수 ÷ 그 분기 전체 주제 언급 문서 수
```

**"문서 기준 비율"(주제 문서 수 ÷ 전체 문서 수)을 쓰면 안 되는 이유가 실측으로 나왔습니다.**

유튜버 설명란 길이 중앙값이 3년간 **1,253자 → 709자(−44%)**로 줄었습니다. 채널 수는 그대로입니다. 텍스트가 짧아지면 분자(언급)만 줄고 분모(영상 수)는 그대로라서 비율이 구조적으로 내려갑니다.

| | 문서 기준 비율 | composition |
|---|---|---|
| 13주제 변화량 합계 | **−28.6%p** | −0.0%p (정의상 0) |
| 하락한 주제 수 | **10 / 13** | 6 / 13 |
| 변화량 절대값 평균 | 2.46%p | 1.12%p |

문서 기준으로 판정하면 **13개 주제 중 10개가 "사라짐"**으로 분류됩니다. 트렌드가 아니라 유튜버들이 설명을 짧게 쓰기 시작한 것입니다. 구성비는 분자와 분모가 같이 줄어 이 드리프트가 상쇄됩니다.

### 비교는 전년 동분기(YoY)

```
velocity = log(이번 분기 composition) − log(전년 동분기 composition)
```

선크림은 계절 상품이라 Q2가 3년 연속 최고(26.7% / 25.3% / 25.6%)이고 Q1·Q4가 최저입니다. **인접 분기를 비교하면 매년 Q2에 급상승, Q4에 사라짐이 나옵니다.** 트렌드가 아니라 여름입니다.

### 나머지 지표 4개

| 지표 | 정의 |
|---|---|
| `persistence` | 최근 4분기 중 `composition`이 그 주제의 전체 기간 중앙값을 넘는 분기 수 |
| `channel_diffusion` | 고유 채널 수 50% + 채널 분포 엔트로피 50%. 비율만 보면 "3채널 골고루"와 "1채널 독점"을 구분 못 함 |
| `evidence_strength` | 유효 근거 수 43.75% + 고유 채널 수 31.25% + 비중복 비율 25% (원안 4요소 중 제품 매칭 항은 `entity_link` 전이라 3요소 재정규화) |
| **`gap`** | **댓글 composition − 영상 composition** |

### `gap`이 제품 공백 신호입니다

**영상과 댓글을 절대 섞지 않습니다.** 각자 자기 분모로 계산하고 차이를 봅니다.

섞으면 안 되는 이유가 실측으로 나옵니다 — `백탁`은 영상 설명에서 **13분기 전부 표본 부족**이고 댓글에서는 **12분기 충족**입니다. 밀림·들뜸은 영상 1분기 대 댓글 13분기입니다. 영상 설명은 스펙·포뮬러를, 댓글은 사용감·불만을 담습니다. 섞으면 이 차이가 사라집니다.

> 댓글에서는 오르는데 영상 설명에서는 안 오르는 주제 = 소비자는 말하는데 제작자·브랜드는 아직 다루지 않는 주제 = **제품 공백 기회**

2026Q2 최대 갭은 **자극·눈시림 +5.29%p**입니다.

## 4. 판정 규칙

임계값 **τ = 0.35** (log 차이 단위, 구성비 약 1.42배). 실측 YoY 분포 75분위에서 뽑았습니다 — 영상 0.366, 댓글 0.358로 두 소스가 독립 계산인데 거의 일치합니다. **한 번 뽑아 고정하고 분기마다 재계산하지 않습니다.** 재계산하면 아무 변화 없는 분기에도 상위 25%가 급상승으로 찍힙니다.

위에서 먼저 걸리면 종료합니다.

```
근거 부족   evidence_strength < 50  또는  document_count < 5
신규 등장   직전 3분기 composition < 1%  &&  현 분기 document_count ≥ 5  &&  채널 2개 이상
단기 피크   velocity > +τ  &&  persistence = 1
급상승      velocity > +τ  &&  persistence ≥ 2
채널 확산   channel_diffusion 전년 동분기 대비 +0.089 초과  &&  velocity ≤ +τ
지속 인기   |velocity| ≤ τ  &&  persistence ≥ 3
사라짐      velocity < −τ  &&  현 분기 composition < 최고 분기의 절반
```

미해당은 `판정 보류`, 진행 중인 마지막 분기는 `미확정`으로 둡니다.
`opportunity_score` = velocity 0.35 + persistence 0.25 + channel_diffusion 0.20 + evidence_strength 0.20, 제품군 내 0~100 정규화.

**`source_count ≥ 2`는 유튜브 내부 판정에 적용하지 않습니다.** 영상과 댓글은 상호 검증 소스가 아니라 성격이 다른 두 계열이고, 그 차이를 `gap`으로 쓰기로 했기 때문입니다. 대신 `single_source` 플래그를 남깁니다. 플랫폼 간(유튜브·네이버·커머스) 교차 확인에는 적용합니다.

**판정된 것은 64셀이고 81%는 판정하지 않았습니다.** 이걸 숨기지 않고 `hold_reason`으로 출력하는 것이 이 파트의 원칙입니다.

`채널 확산` 임계값은 조였습니다. 처음엔 "0보다 크면 상승"이어서 판정 89셀 중 52셀(58%)이 여기로 쏠렸습니다. τ와 같은 방법으로 실측 분포 75분위(0.089)를 뽑아 적용하니 52 → 14셀이 되고, 남은 것은 +0.10 ~ +0.54의 실제 도약입니다. **이 값도 소스마다 다시 뽑아야 합니다.**

### 광고·협찬을 빼면 결론이 바뀝니다 (필터 민감 신호)

선크림 장문 964편 중 **465편(48.2%)이 광고·협찬**입니다. `has_paid_product_placement` 신고는 254편뿐이고 설명란 문구로 407편이 걸립니다 — 신고 필드만 믿으면 절반을 놓칩니다.

빼고 다시 계산한 결과입니다(`spam_ad_flags.py`).

| 제외 대상 | 유형이 뒤집힌 셀 | 표본 미달로 판정이 사라진 셀 | 최대 구성비 변화 |
|---|---|---|---|
| 광고·협찬 영상 465편 | **19 / 64** | 24 | +2.40%p (무기자차) |
| 운영자 댓글 709건 | 2 / 64 | 5 | −0.56%p (톤업_메이크업베이스) |
| 홍보 댓글 17건 | 0 / 64 | 0 | −0.02%p |

**그래서 광고·협찬 영상은 빼지 않고, 대신 필터 민감으로 표시합니다.** 빼면 모집단이 절반이 되어 판정 24셀이 표본 미달로 사라집니다. 남기면 결론이 광고에 실려 있습니다. 어느 쪽도 공짜가 아니므로 숫자를 그대로 공개하고 카드에 이 사실을 붙입니다.

운영자 댓글 709건은 채널 운영자 본인이 쓴 것으로, `author_channel_hash = sha256("youtube:" + channel_id)[:24]`로 **정확히** 식별됩니다(추정이 아닙니다). 제품 정보·타임라인·판매 링크라 설명란을 옮긴 것에 가깝고, 댓글 계열을 "소비자 반응"으로 쓰는 정의와 어긋납니다. 다만 영향이 2셀이라 현행 계산은 그대로 두고 표시만 남깁니다.

홍보 댓글은 17건뿐입니다. 전화번호·도박·대출 정규식은 재보니 걸린 10건이 거의 전부 오검출(`토토톡`, `40대출산맘`, `무향`)이어서 **버렸습니다.**

## 6. 미결 · 한계

**미결 — 태그를 판정 텍스트에 넣을지.** 기획안 문장은 "제목+설명+태그"인데 계산은 제목+설명만 씁니다. 태그를 넣으면 모집단이 **964 → 1,019편**이 되고 모든 구성비가 움직입니다. 태그는 `source_metadata.tags`에 보존돼 있어 재수집 없이 바꿀 수 있습니다.

**기획안의 962편은 옛 값입니다.** 지금 스크립트를 돌리면 964편입니다. 보고서에는 964를 씁니다.

**한계**
- `백탁`·`밀림_들뜸`·`유기자차`는 영상 설명만으로 측정 불가(충족 0·1·3분기). 댓글 계열에만 의존하므로 댓글이 끊기면 관측이 끊깁니다
- `혼합자차`는 영상 3·댓글 7분기로 양쪽 부족 → 판정 보류
- 모집단은 고정 패널 43채널이며 전체 YouTube가 아닙니다. 패널 밖 신규 채널·브랜드는 관측되지 않습니다(NAVER가 보완)
- 사전에 없는 표현은 관측되지 않습니다. `신규 등장`이 잡는 건 사전에 이미 있는 13개 중 새로 뜬 것뿐입니다. 사전 밖에서 실제로 뭐가 빠졌는지는 `unmatched_terms.csv`가 보여줍니다 — 성분표에 있는데 사전에 없는 말이 11종(나이아신아마이드 394제품 · 판테놀 207 · 마데카소사이드 70 · 스쿠알란 61 · 엑토인 38 · 구아이아줄렌 14 외)입니다. **추가는 팀 합의 후에 합니다** — 추가하면 τ·판정·카드가 전부 다시 계산됩니다
- 댓글은 계속 쌓이므로 최근 분기가 구조적으로 과소 집계됩니다
- 조회수·좋아요는 수집 시점 스냅샷이라 트렌드 점수에 직접 쓰지 않습니다
