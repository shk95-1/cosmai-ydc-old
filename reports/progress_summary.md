## 4. 검색 계층 — 만들고 **측정**했습니다

| 모드 | bm25 | vector | hybrid |
|---|---:|---:|---:|
| `literal` P@10 | **0.828** | 0.567 | 0.710 |
| `heldout` P@10 | **0.000** | **0.042** | 0.032 |
| `heldout` Hit@10 | 0% | **17%** | 13% |

**채택 기준을 결과 보기 전에 정했습니다.** `heldout` 에서 BM25 는 구조적으로 0.000
입니다(정답을 "질의 토큰이 없는 문서"로 잡았으니). 그래서 기준은 **"0을 넘느냐"**
였고, 벡터가 0.042 로 넘었습니다.

**이긴 자리가 명확합니다** — 점수 대부분이 `톤 업`(P@10 1.00)·`눈 시림`(0.60)에서
나옵니다. 둘 다 **공백이 든 별칭**이라 BM25 는 토큰화하면 조각나서 0점입니다.

**하이브리드(RRF)는 폐기했습니다.** 어휘 0.828 → 0.710, 의미 0.042 → 0.032 으로
**양쪽을 깎았습니다.** 순위만 보고 확신도를 무시하기 때문입니다.

```
성분명 · SPF · 브랜드 (정확 일치가 정답)   →  BM25
"하얗게 떠서 싫다" (이름 없는 표현)         →  벡터
```

**근거는 합치지 않고 나란히 놓습니다** — 소스를 합산하지 않은 것과 같은 논리입니다.

### 소스별로 나눠 물어야 합니다

전역 상위 k 를 쓰면 색인의 92%인 짧은 유튜브 댓글이 상위를 독점합니다
(`mfds` 전역 293위 · `ingredient` 300위 밖). `--per-source` 로 물으면 이렇게 됩니다.

```
질의: "판테놀 쓰는 선크림"
[youtube_comment]  판테놀 무기자차 선크림 진리임..ᅲ
[formula_full]     제로이드 데일리 선크림 — 전성분 26.판테놀
[mfds]             앤서나인틴시카판테놀데일리선크림 · 2019-04-15 · SPF50+ PA++++
[ingredient]       판테놀 — 209개 제품 36.2% · 평균 배합순위 28위
```

**한 질의가 담론·처방·등록원부를 동시에 답합니다.** LLM 이 숫자를 답할 때 그 숫자의
**원문 근거**를 대는 자리입니다.

## 5. 검증 — 결론이 얼마나 버티나

| 검증 | 결과 |
|---|---|
| 패널 민감도 | expert 포함/제외 → 뒤집힘 **0셀** |
| 광고·협찬 민감도 | **48.2%가 광고. 빼면 19셀 뒤집힘** |
| 재실행 일치 | 커밋된 338행 **전부 재생성**. 버그 1건 발견 |
| 오류 주입 | **21개 통과** (429 vs 403 구분 포함) |
| 후향 검증 | **예측력 없음** |
| 사전의 천장 | 성분표에 있는데 사전에 없는 말 **11종** |

### 예측이 안 됩니다

| 기준 | 적중 | 기저율 |
|---|---:|---:|
| A 판정 후에도 계속 올랐나 | **27%** | 47% |
| B 올라간 수준이 유지됐나 | 64% | 47% |
| A (상승 계열 9건만) | **22%** | 47% |

13분기 · 계절 상품 · 964편으로는 예측 모델을 세울 수 없습니다.
**기저율을 같이 낸 것이 중요합니다** — 적중률만 내는 검증은 검증이 아니라 홍보입니다.

> 팀의 ML 파트도 독립적으로 같은 곳에 도달했습니다 — 모델 A 가 baseline 상대로
> 9판 6승 3패, 모델 E(논문 수 → 매출)는 넣으니 오히려 나빠졌습니다.

### 광고는 빼도 안 빼도 손실입니다

선크림 장문 964편 중 **465편(48.2%)이 광고·협찬**입니다. 신고 필드는 254편뿐이고
설명란 문구로 407편이 걸립니다 — **신고만 믿으면 절반을 놓칩니다.**

빼면 판정 24셀이 표본 미달로 사라지고, 남기면 결론이 광고에 실립니다.
**공짜인 선택지가 없으므로 빼지 않고 필터 민감으로 공개**합니다.

## 6. 같은 함정을 다섯 번 밟았습니다

**다섯 번 다 오류가 안 나고 결과가 그럴듯했습니다.**

| 언제 | 무엇이 관측값이 됐나 | 어떻게 알았나 |
|---|---|---|
| 수집 초기 | **수집 상한 10** | 월별 집계가 매달 10건 근처 |
| 08.23 | **추출 방법** (정렬 없는 페이징) | **현준님이 재현 안 된다고 알려주심** |
| 08.24 | **소스 비율** (색인 92%가 짧은 댓글) | 소스별로 나눠 물어보니 드러남 |
| 08.24 | **id 형식** (정답 `doc_id` vs 결과 `chunk_id`) | 벡터가 0.000 이 나와서 의심 |
| 08.25 | **정규화 시점** (수호님은 정규화 전 본문으로 인코딩) | 프로브 코사인 0.9986 |

두 번째는 제가 **"커머스 랭킹에 완전 중복 37%"** 라고 잘못 보고한 건입니다.
서버가 아니라 제 추출 문제였고 정정했습니다. **그때 제가 지운 게 중복이 아니라
결과 하나였습니다** — 올리브영 100위권은 실제로 6일에 38계단 움직이고, 프로모션이
랭킹을 미는 구조입니다.

네 번째가 가장 아까웠습니다. 그대로 봤으면 **"임베딩은 이득이 없다"고 잘못 결론
내리고 발표했을 겁니다.**

### 그래서 자기 검사를 코드에 박았습니다

| 장치 | 무엇을 막나 |
|---|---|
| 행수 대조 | 페이징 중 집합 변화 (서버 `count=exact` 와 안 맞으면 중단) |
| 재현성 검사 | 커밋 산출물이 지금 코드로 안 나오는 것 |
| 계약 검증기 | 청크 위반 11종 |
| 기저율 병기 | 적중률만 내는 자기 홍보 |
| 캐시 키에 설정 해시 | 설정을 바꿔도 옛 색인을 쓰는 것 |
| 채택 기준 사전 고정 | 결과를 보고 기준을 만드는 것 |
| 합치기 전 코사인 실측 | 남의 벡터가 다른 공간인 것 |
| `--demo` | 데이터 없이 로직이 죽은 것 |

**문서에 적어 두는 것보다 낫습니다.**

## 7. 세 소스가 같은 장치를 필요로 했습니다

이게 이번 작업에서 가장 흥미로운 부분입니다.

| 소스 | 문제 | 장치 |
|---|---|---|
| 유튜브 | 설명란이 3년간 44% 짧아짐 | **`composition`** (주제 간 구성비) |
| NAVER | 요청마다 최대 100 정규화 | **`기준_세럼`** 대비 지수 |
| 논문 | 색인 성장률이 다름 (EPMC 2.10x · PubMed 1.44x) | **`cosmetic`** 대비 보정 |

전부 **"전체가 커진 만큼을 빼야 그 항목이 진짜 늘었는지 보인다"** 는 같은 문제입니다.

논문에서 그 효과가 극적입니다. 보정 전에는 두 색인이 완전히 달라 보였는데,
보정하니 **표본 충분한 10개의 차이가 평균 0.083** 으로 좁혀졌습니다.

```
             원본 EPMC / PubMed      보정 후
트라넥삼산      2.43 / 1.66          1.16 / 1.15   차이 0.00
아데노신        1.64 / 1.11          0.78 / 0.77   차이 0.01
센텔라          3.63 / 2.45          1.73 / 1.70   차이 0.03
```

현준님이 *"두 색인이 다른 걸 센다"* 고 하신 게 맞는데, **다른 건 색인의 성장률**
이었습니다. 나이아신아마이드(1.00 vs 0.63)만 여전히 갈리고, 그게 유일하게 진짜
이견인 성분입니다.

## 8. 팀에서 서로 잡아준 것

**현준님이 제 오보를 잡았습니다.** 커머스 중복 37% 는 제 페이징 문제였습니다.
그가 재현이 안 된다고 바로 알려주지 않았으면 잘못된 숫자로 발표했을 겁니다.

**현준님이 아데노신을 막았습니다.** 논문 월 900~2,600편은 화장품과 무관한

주장하려던 참이었고, 보정해 보니 **0.78 로 오히려 뒤처집니다.**

**현준님이 `review_topic` 을 재줬습니다.** 사이트 객관식이라 백탁이 0건입니다.
그 덕에 **커머스 리뷰 본문 18,476청크가 임베딩 대상에서 빠져 있던 걸** 찾았습니다.

**수호님이 제 28건을 확인해 줬습니다.** 뭉친 셀 탐지에서 우리 28건이 맞고 그의
21건이 부분집합이었는데, 그가 셀 단위로 다시 스캔해 26건을 복구했습니다.
남은 2건은 **잘못 자르는 것보다 안전하다고 판단해 원본 유지** — 우리와 같은 판단입니다.

**수호님이 배합 순위를 제안했습니다.** 순번이 없으면 MASTER_REPORT 의 "미백만
고함량 배치" 발견을 검색으로 재현할 수 없다는 지적이었고, 맞았습니다.
지금 대조표 §3-1 이 그 순번 위에 서 있습니다.
