# 발표 자료 빌더

NVIDIA 규격 양식(`NVIDIA규격_PoC_프로젝트_발표자료_양식.pptx`)에 우리 내용을
채워 26장을 만든다. **양식의 좌표·색·글꼴·6절 구조를 건드리지 않는다** —
텍스트를 채우고 회색 안내문을 지우고, 6절 안에 시각화 장을 끼운다.

```bash
PY=C:/Users/Admin/miniconda3/python.exe
$PY -X utf8 deck/build.py      # 산출 → Downloads/[1팀_리메릭]발표자료_260827_COSMAI.pptx
$PY -X utf8 deck/verify.py     # 양식 잔재·금지 표현·화면 밖 도형·페이지 번호 검사
$PY -X utf8 deck/shots.py      # PowerPoint 로 26장을 PNG 로 내보낸다 (넘침 확인)
```

## 왜 손으로 안 만드나

숫자가 26장에 흩어져 있고 정정이 계속 나온다. 08.26 판에서 시카 41.1%·논문
배수·Hybrid 해석이 각각 다른 장에 남아 있었다. **스크립트로 만들면 정정이 한
곳에서 끝나고, `verify.py` 가 잔재를 잡는다.**

## 구성

| 파일 | 역할 |
|---|---|
| `pptlib.py` | 서식을 보존하는 텍스트 교체 · 표 채움 · 슬라이드 복제 · 네이티브 도형 차트 |
| `build.py` | 26장의 내용 (parts 를 합쳐 넣은 단일 스크립트) |
| `part3~7.py` | build.py 에 붙였던 조각. 이력용으로 남긴다 |
| `verify.py` | 자기 검사 |
| `shots.py` | PNG 내보내기 |

## 규칙

- **`text_frame.text = ...` 를 쓰지 않는다.** 런을 지워 양식 서식이 날아간다.
  `set_text()` 가 첫 문단을 서식 기증자로 복제한다
- **회색 안내문은 색(`B5B5B5`)과 `※` 로 찾아 지운다.** 이름으로 지우면 장마다
  도형 이름이 달라 깨진다. **단, 페이지 번호도 `B5B5B5` 라 y≈7.05 의 숫자는 남긴다**
- **차트는 이미지가 아니라 도형이다.** 팀원이 숫자를 고칠 수 있고 한글 폰트가
  없는 PC 에서도 깨지지 않는다
- **계열 색은 `validate_palette` 를 통과한 조합이다** (`5B3FD6` · `C2410C` · `0284A8`).
  색만으로 구분하지 않으려고 모든 막대에 값을 직접 적고 범례를 붙인다
- **막대 상한은 비교 단위마다 따로 잡는다.** 100% 로 고정하면 7~17% 값이 선이 된다
- **표의 마지막 행을 복제해 행을 늘린다.** 양식의 마지막 행이 `미달`(빨강)이라
  판정 열은 `verdict_col` 로 값에 맞춰 다시 칠한다
